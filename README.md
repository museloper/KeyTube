# KeyTube

YouTube 음원의 키를 반음 단위로 올리고 내리며, 원키와 바뀐 키를 보여주는 연습 도구. 자매 프로젝트: [LoopTube](https://github.com/museloper/LoopTube).

배포: https://museloper.github.io/KeyTube/ (데스크톱 Chrome·Edge에서 키 조절 가능)

```bash
npm install
npm run dev      # http://localhost:3000, 캡처 검증은 /debug
npm test
```

설계와 로드맵은 [`docs/PLAN.md`](docs/PLAN.md).
